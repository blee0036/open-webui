## 已实际操作的界面与链路

- 登录页显示两个独立企业连接（中国飞书、国际 Lark）；管理员可以查看企业连接、默认套餐、个人继承、追加额度、定价和审计入口。
- 真实 WebUI API 连接本地假模型，调用真实项目沙盒执行 Python，再进行模型续轮。生成 `agent-chart.png`、`agent-report.xlsx`，计算结果为 **540**；账本恰好记录 **2 次已结算推理**。
- 在界面预览图表和 Excel，Excel 显示 Jan 120、Feb 180、Mar 240；显式发布图表后，它出现在项目参考资料中。工作区文件下载链路与 XLSX 内容有效性已检查。
- 普通成员使用 Playground 耗尽三次验收套餐后，显示额度耗尽及下次重置时间。后续请求没有模型出站或新增用量；历史、文件和个人提示词创建仍可用。验收后恢复默认套餐继承，保留真实已用量。
- 普通成员在界面创建并立即运行自动化任务，后台推理成功且只扣创建者 **1 次**，管理员额度未变、没有遗留预留；生成的对话可打开。验收任务已暂停，不继续周期运行。
- 资源中心保留模型、知识库、提示词、Skills 和 Tools；成员成功创建个人提示词。设置保留个人 MCP、OpenAPI 和 Open Terminal，没有个人模型直连入口。
- 实际检查交互终端、容器内浏览器与桌面；检查 1440×1000 桌面布局及 390×844 移动端额度／工作环境页面。

模型与身份自动化测试使用本地桩；没有调用收费模型或真实企业账号。沙盒、MCP 协议、浏览器界面和自动化后台执行使用真实本地服务。SearXNG 自托管实例的 JSON 检索返回 HTTP 200；生产 Embedding／RAG 索引仍需在目标部署中验证。
